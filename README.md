# SessionTap

SessionTap is a local, vendor-neutral observability wrapper for explicitly
launched Claude Code, Codex, and Qwen terminal sessions. The project is an MVP
under active development; its product name is a development codename pending
clearance.

The first-party target is Linux running a Wayland session. The upstream project
does not support macOS, Windows, or X11; downstream forks may add those targets.

See `docs/cli.md` for usage and `docs/clean-room.md` for provenance rules.

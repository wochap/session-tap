SessionTap
Android monitor for coding agents across paired hubs, plus a live view of each agent's terminal on hubs that grant Watch, and replies on hubs that grant Control. Material 3 structure (top app bar, chips, nav bar, switches, dialogs, notification templates) skinned with Nocturne tokens; status color is the only saturated color. Every phone is live — tap rows, chips, section headers, the agent badge, swipe stopped rows left, and use the nav bar.
Assumptions: amber/red/green status hues added in OKLCH (not in Nocturne)Provider marks are letter placeholders until real iconsLight theme derived from Nocturne neutral ramps
13Terminal · select & copyLong-press a word, drag the teardrop handles, Copy. Highlight is one contiguous cell range. Phones are live: long-press any text, drag handles (to the top/bottom edge to auto-scroll), tap outside to leave.
13Gesture rules · normal vs selecting
Gesture on the paneNormalSelecting
Long-press · 450msSelects the word under the finger, enters selectingMoves the selection to the new word
Drag on textPans sideways, scrolls backSame. The selection stays pinned to its cells
Drag a handle—Moves that end, one cell at a time with a haptic tick. Loupe shows. Handles can cross (they swap roles)

Back gestureLeaves the terminalEnds the selection only
Key bar, Send, IME keySendsEnds the selection, then sends
Jump to liveBack to liveEnds the selection, back to live
WordRun of letters, digits and _ . / ~ : @ + - ' — paths and flags select whole. Trailing . : , ' are dropped.
HighlightOne contiguous range, start cell → end cell, wrapping like an editor. Selected cells paint the default pair (fg as background, bg as text) instead of a per-cell swap — a swap makes cells that already have a background look unselected (13k). Trailing blanks are skipped; one cell after each row marks the line break.
CopyPlain text of the range, trailing spaces trimmed per row. Rows that tmux marks as soft-wrapped are joined (like capture-pane -J), so there is no separate "copy joined" option; newlines the agent printed are kept.
FreezeSelecting freezes the view, the same as scrolling up. New output collects below and the pill counts it. Leaving returns to live, unless you were already scrolled up.
ToolbarAbove the selection, 10dp gap. If that crosses the chip row (top 36dp), it goes below the end handle. If neither fits, it pins under the chip row. It lives inside the pane, so it can never cover the top app bar. Keeps 54dp clear at the bottom while the pill shows. Hidden while dragging.
PrecisionThe handle tip sits on the cell edge, with the finger 22dp away. Drag is relative, so the handle never jumps to the finger. The loupe shows ±7 cells at 18sp with an accent edge marker. At fit, cells are ~3.3dp, so the loupe is the target; pinch in at any time.
Toast"Copied · N lines" at the bottom of the pane for 2.2s, inside the terminal, so it never covers the key bar or input. Stacks above the pill when the pill is showing.
